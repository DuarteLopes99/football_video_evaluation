# Match recordings

Put full-match videos here (`.mp4`, `.mov`, `.mkv`, `.m4v`). This folder is the **Local** video library of
`configs/storage.yaml` and is git-ignored. Naming that keeps the list readable:

    YYYY-MM-DD_<Home>_vs_<Away>_<competition or round>.mp4      e.g. 2026-10-18_UD_Mansores_vs_Canedo_FC_J2.mp4

Ways to add one: drop it on the launcher (`python scripts/launcher.py`), or copy it into this folder.
Not enough disk space for every match? Add an external drive or a cloud-synced folder as another library and
archive analysed matches there — see `docs/VIDEO_STORAGE.md`.
